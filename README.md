# Jawai Retreat

Website for Jawai Retreat, a boutique wilderness retreat in Pali District, Rajasthan.
Built with React, Vite, Tailwind CSS and Motion.

## Run locally

Requires Node.js 20+.

```bash
npm install --legacy-peer-deps
npm run dev
```

The site runs at http://localhost:3000.

## Build

```bash
npm run build
npm run preview
```
